# Tools

Use only tools listed in the current runtime catalogue. Do not rescan or select outside the authoritative context. Tool calls contain only the advertised draft arguments; Python supplies identity and authorization.

`inspect_shortcut_methods` supplies cited mechanism/method memory and execution prerequisites. Its entries are hypotheses to compare with current observations, never evidence about this dataset.

search_shortcut_literature is Identify-only, network-policy controlled and bounded. It retrieves public arXiv metadata/abstract excerpts using generic topic phrases. Requesting it cannot override an offline policy. It never supplies a quantitative ToolResult or silently downloads/executes a validation method.
